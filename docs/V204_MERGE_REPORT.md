# 合入 v2.0.4 的兼容改进

基于当前功能源码合入 v2.0.4，对外版本号未变更；不直接覆盖现有评分与库存实现。

- 存档管理采用 v2.0.4 的滚动页面、用户、当前存档、六条备份高度及规则检查布局，保留打开两个存档目录的按钮。
- 增加当前、备份和外部存档只读规则检查及独立 ID 一致性开关。校验不影响库存、评分或配装。
- 校验器继承现有读取器，保留 handle/acquisition 实物标识；库存同步不加载生成池规则表，校验时按需加载。
- 加入商店逐件按键优化、十连分项耗时统计，以及沿用评分匹配语义的购买前配置检查。
- 保留本次三有效记录功能、评分、负面分级、预设继承和导入导出。
- OCR 固定本地 PP-OCRv6-small，仅初始化识别器，保留换行纠错；RapidOCR 固定 3.9.2，打包仅携带所需识别模型。
- 合入启动设置容错、OCR 失败日志与退出线程清理。
- 已存在的 Steam 路径管理、多屏、分辨率和亮度检查不重复替换。
