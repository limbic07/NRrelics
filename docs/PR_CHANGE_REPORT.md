# 增加遗物综合评分、库存管理与配装优化

## 对比范围

本文描述最终版本相对于原作者仓库 `master` 分支提交 `a318132` 的变化。原版源码 ZIP 中的 Python、打包配置、TXT 和 Markdown 文件已与该提交核对一致。

## 功能变化

### 综合评分与分级预设

- 在原有双有效、三有效筛选之外，增加可选的综合评分、保留线和备选线。关闭综合评分时仍沿用原有筛选方式。
- 正面词条分为重要、次要、锦上添花；深夜负面分为不可接受、很伤、几乎无负面。分数和阈值可在设置中调整。
- 专用预设继承通用预设，并可覆盖词条等级、排除继承词条，或将特定负面按正面效果计分。
- 预设导入、导出包含评分配置，同时兼容没有评分字段的旧预设。

### 内置流派与官方遗物

- 内置按角色划分的普通和深夜流派预设，无需额外导入 JSON。新建专用预设时选择角色，名称自动带有角色前缀，供配装页面归类。
- 内置 118 件官方遗物的名称、颜色和固定词条，并默认加入可用库存。官方遗物不可编辑或删除；普通预设可为每件官方遗物指定整体分数。未指定时按有效词条计分。
- 官方遗物评分界面可展开查看固定词条。商店和仓库页面增加经二次确认的“恢复默认预设”操作。

### 仓库检索与逐件筛选结果

- 增加 `F9` 仓库检索：复用仓库遍历和识别流程，只录入遗物，不执行收藏或售出。
- 仓库筛选逐件记录识别词条、评分明细、总分、有效词条数、匹配预设、筛选判定和实际操作结果，并同步到日志和仪表盘。
- 筛选判定与实际操作分别保存。OCR 不完整时避免破坏性操作；操作未确认时将记录标为待核实。
- 增加红、蓝、绿、黄遗物图标颜色识别；置信度不足时记录为颜色未知。

### 遗物管理

- 新增独立的遗物管理页面，使用 SQLite 保存本地库存、扫描记录和评分快照。词条相同的两件实物仍各自保留记录。
- 支持添加、双击编辑、按词条查询和批量删除非官方遗物。编辑时从可搜索的词条库选择，不直接输入任意词条。
- 深夜遗物最多三组词条；每组最多一条正面和一条负面，且负面必须配有正面。

### 配装优化

- 新增独立的配装优化页面，可分别选择普通和深夜预设，也可只优化其中一类。
- 根据角色可用器皿、槽位颜色、现有库存和词条计分求解组合。用户可指定必备词条或官方遗物：同组满足任意一项，不同组全部满足；普通和深夜的同名词条共用一个条件。
- 达标比例默认是最优分的 75%。先展示前 10 套，用户继续请求时再求后续 10 套；同一组遗物的槽位排列不重复展示。
- 计分区分可叠加、同名去重及特殊叠加规则。只有求解器确认最优时才返回对应排名；无法证明最优时报告求解失败。
- 结果按器皿槽位从左到右显示库存行号、颜色、词条及其分数、单件贡献和组合总分。

## 界面变化

- 商店和仓库共用分级预设编辑器：先选等级，再选择词条，并可查看已选词条及其等级。
- 可勾选列表支持右键整行切换；数值框和下拉选项不响应滚轮改值。
- 遗物表格采用固定的信息列宽、悬停效果和官方遗物锁定标记，禁止直接修改表格文本。
- 存档管理增加打开备份目录与游戏存档目录的快捷按钮。
- 预设列表在页面首次显示时加载，折叠词条在首次展开时创建；创建、编辑、删除预设只更新相关卡片，并同步另一个页面。

## 实现与依赖

| 部分 | 主要变化 |
| --- | --- |
| `core/relic_matcher.py`、`core/relic_scoring.py` | 在共享匹配器中增加分级计分、最高分候选和未通过原因，供商店与仓库使用。 |
| `core/preset_manager.py` | 管理等级、继承覆盖、官方遗物分数、内置预设及旧数据兼容。 |
| `core/repo_cleaner.py`、`core/relic_inventory.py`、`core/relic_color.py` | 接入逐件扫描、颜色识别、操作确认和 SQLite 持久化。 |
| `core/loadout_optimizer.py` | 使用 SciPy MILP 求解配装，避免把同组遗物的槽位排列重复计为不同组合。 |
| `core/official_relics.py`、`data/` | 提供官方遗物目录、内置流派、器皿资料和颜色模型。 |
| `ui/`、`main.py` | 接入管理与优化页面、预设编辑、评分配置、结果展示和输入行为。 |

库存使用标准库 `sqlite3`；界面沿用 PySide6 和 Fluent Widgets。新增 SciPy 用于组合优化，scikit-learn 与 joblib 用于颜色模型。打包资源显式列出，用户配置、库存和备份留在程序外部；开发、绘图模块及 OpenCV 视频解码库不纳入发布包。
