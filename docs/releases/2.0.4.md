# NRrelic Bot 2.0.4

- **遗物规则检查**：支持按角色检查当前存档、备份和外部存档，显示合法、不合法或无法判定。
- **ID 一致性开关**：可额外检查遗物 ID 与词条是否对应；组合合法但 ID 不一致的遗物仍视为合法。
- **分组预设**：必须词条支持组内任选、组间全满足，兼容旧预设。
- **Steam 路径管理**：支持浏览修改和自动检测其他磁盘的 Steam 安装路径。
- **多屏与环境检查**：改善副屏识别，启动前检查 16:9 分辨率，仓库清理前检查游戏亮度。
- **调试开关**：新增 OCR 数据采集和耗时调试，便于排查识别及效率问题。
- **流程与界面优化**：改善商店筛选效率和仓库清理稳定性，备份列表可同时显示更多记录。
