# NRrelic Bot 2.0.4

发布日期：2026-10-14

## 新增与改进

- 支持分组必须词条：组内满足任一词条，组间全部满足；兼容旧预设。
- 存档管理新增只读遗物规则检查，可检查当前存档、备份及外部 `.sl2` / `.co2` 文件，并按角色查看结果。
- 符合当前已知词条组合生成规则即视为合法遗物。新增默认关闭的“检查 ID 一致性”开关，ID 不通过单独展示，不影响合法性统计。
- Steam 安装路径支持浏览修改和自动检测，包括其他磁盘安装目录。
- 存档管理页调整为当前存档、备份列表、遗物规则检查；备份列表预留六条记录的显示空间。
- 新增 OCR 调试采集与耗时调试开关，便于保存截图、原始识别、纠错、匹配结果及耗时。
- 优化商店筛选中的等待和截图流程，保留原有六行单行 OCR 识别方式。

## 修复

- 修复副屏截图和 OCR 的坐标处理，启动自动功能前检查实际画面是否为 16:9。
- 改进仓库光标检测、官方特殊遗物标记识别，以及最后一行的结束判断。
- 合格数量停止条件移至商店设置，移除仓库清理的完美遗物停止功能。
- 检查仓库清理所需的游戏亮度设置，推荐亮度 5。
- 修复损坏设置文件导致主程序或商店页启动失败的问题，补充 OCR 初始化失败日志和退出时线程清理。

## 打包与更新

- 窗口标题、关于页及 Windows 可执行文件版本统一为 2.0.4。
- 内置 `PP-OCRv6_rec_small.onnx` 识别模型，只加载识别路径，不包含 DET/CLS 模型，不需要联网下载模型。
- 清理旧 Conda 路径依赖，仅打包运行资源。发布包不包含个人预设、设置、存档备份或调试文件。
- 关闭旧版后，将旧程序同级 `data/` 文件夹复制到新版同级目录即可保留用户数据；完整保留新版 `_internal`。

## 检查范围

遗物规则使用当前随程序附带的社区参数快照，未知数据仍显示“无法判定”。
发布构建包含自动回归与打包后运行检查；实际游戏中的长时间商店购买和仓库清理仍需游戏内验证。
