# 合入 v2.0.4 改进，增加本次三有效记录并更新文档

## 对比范围

相对于作者 master 提交 `a4b8700dd0a7ea5170a6d1ed7eb92ed4d103bb30`。保留现有评分、存档库存同步与配装优化，不将已合并功能重复列为新增。

## 功能变化

- 存档管理采用 v2.0.4 的滚动卡片布局，调整备份列表显示高度，保留打开备份和游戏存档目录的按钮。
- 新增当前、备份及外部存档的只读遗物规则检查，可按存档角色查看结果；ID 一致性默认关闭并单独展示。检查结果不影响库存、筛选或配装。
- 校验器复用库存读取器，保留物品身份字段，库存同步不加载生成池规则表。名称优先沿用现有词条库。
- 商店逐件操作保留 100 毫秒按住时间，缩短释放后等待至 80 毫秒；异常时确保释放按键。增加可选的十连分项耗时汇总。
- 购买前检查预设配置，沿用现有评分匹配语义，避免将配装必备条件误用于单件筛选。
- 商店仪表盘增加本次三有效遗物查看按钮，实时记录同一预设下至少三条正面有效词条的结果，包括评分未通过及 SL 还原前的记录；新购买会话清空。
- OCR 固定本地 PP-OCRv6-small 识别模型，仅初始化识别器；保留送葬者换行纠错。修复启动配置容错、OCR 失败日志及初始化线程退出清理。
- README 以用户编辑版本为基础，修正预设数量限制、单槽位同步、评分边界及完美遗物条件，补充新增功能。
