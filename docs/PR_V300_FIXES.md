# 3.0.1 修复说明

相对基线 `7842b2d`（3.0.0），本分支包含以下修复。

## 中文路径与仓库清理

模板图片改用文件字节解码，避免 OpenCV 在中文路径下读取失败。模板缺失或损坏时，在游戏操作前停止清理并提示原因，避免连续将遗物判为无法确认。

## 深色界面

原生 Qt 弹窗、表格、词条列表、表头跟随应用主题；移除写死的白色背景，调整结果卡片文字对比度。通过 Fluent 接口关闭云母背景，修复主窗口与侧栏浅底白字。

## 正面词条可设为负面等级

普通、深夜预设均可将正面词条设置为不可接受、很伤、几乎无负面。复用现有负面分值，保存及导入导出沿用原预设结构。此类词条不计入有效词条数量；启用评分时扣分，配装优化也计入相应扣分。深夜编辑扣分等级时，原生负面词条优先列出。

## 验证

已通过中文路径图片解码、损坏模板、清理前检查、预设分级与保存、有效词条计数、优化器扣分、深色背景及文字配色检查；已有评分及预设编辑测试通过。未重复测试未修改模块。实际游戏清理仍需使用新版验证。

没有新增第三方依赖，没有更改库存数据库结构。

## 浅色配色补充修复

显式设置浅色 Qt 调色板，修复预设列表灰褐色背景；深色配色保持独立。新增先深色后浅色的滚动容器配色检查。版本仍为 3.0.1。
