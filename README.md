# NRrelic Bot

一款用于《艾尔登法环：黑夜君临》（Elden Ring Nightreign）的遗物自动化管理工具。<br>
本软件不涉及任何游戏内数据修改，本质上不进行作弊以及任何违反游戏规则的行为。

## ！！注意！！
- 强烈建议仓库清理前利用本软件备份存档<br>
- 请保持游戏界面作为焦点使用<br>
- 商店筛选和仓库清理仅支持游戏实际画面为16:9；建议使用1920x1080或1280x720窗口化<br>
- 仓库清理会在启动前读取最新的游戏存档亮度；建议将游戏亮度设为5，无法读取时会提示手动确认<br>

## 功能概览

### 商店筛选
- 自动在小壶商人处购买遗物（支持十连购买）
- OCR识别遗物词条，根据预设自动筛选
- 支持普通遗物和深夜遗物两种模式
- 支持新旧两个版本遗物切换
- 可设置暗痕停止阈值,低于阈值自动停止购买
- 双有效/三有效匹配模式切换

### 仓库清理
- 自动遍历遗物仪式仓库中的遗物
- 图像识别遗物状态（自由/已装备/已收藏/官方遗物）
- OCR识别词条，根据预设自动筛选
- 两种清理模式：售出模式 / 收藏模式
- 支持自动检测遗物数量或手动设置上限
- 双有效/三有效匹配模式切换

### 预设管理
- 内置共207个流派的遗物预设，并支持自定义新的预设
- 通用预设：适用于所有遗物的词条白名单
- 专用预设：针对特定build的词条组合
- 黑名单预设：深夜模式下排除负面词条
- 词条库支持模糊匹配

### 遗物管理与配装优化
- 选择存档文件自动录入该存档中包含的所有遗物数据
- 根据预设和遗物数据一键优化配装

### 存档管理
- 自动检测Steam用户
- 存档备份与恢复
- 支持多个备份槽位管理



## 使用说明

### 商店筛选
1. 配置词条预设（白名单/黑名单）
2. 选择游戏模式（普通/深夜）和遗物版本
3. 设置停止条件（暗痕数量或合格遗物目标）
4. 打开游戏商人界面
5. 点击"开始筛选"后回到游戏界面

### 仓库清理
1. 配置词条预设
2. 选择游戏模式（普通/深夜）和清理模式（售出/收藏）
3. 设置最大检测数量或自动检测仓库总数量
4. 打开游戏遗物仪式界面
5. 点击"开始清理"后回到游戏界面

### 遗物管理
1. 通过刷新库存按钮选择存档录入遗物数据
2. 向数据库中添加/编辑/删除遗物（不会影响存档）
3. 设置条件筛选遗物

### 配装优化
1. 选择所需要优化的流派
2. 通过添加/编辑/删除条件组，编辑流派的必备词条
3. 点击"计算最优与达标组合"进行一键配装
4. 点击"查看遗物组合"查看配装结果
5. 点击"继续寻找下十套"探索其他配装

### 存档管理
1. 设置Steam安装路径
2. 选择Steam用户
3. 创建备份 / 恢复备份



## 词条匹配规则


### 合格判定
1. 对每套启用的专用预设分别检查必须词条、有效词条数量和黑名单。
2. 有效词条为“通用预设 ∪ 当前专用预设”中命中的不同正面词条。必须词条也计入数量。
3. 双有效模式需要至少2条，三有效模式需要至少3条；命中任意一套即可合格。
4. 深夜黑名单按预设应用例外：例外仅容忍负面词条，不计入有效数量，也不影响其他预设。
5. OCR不完整或遗物状态未知时禁止自动售出/取消收藏。
6. 专用预设可使用分组必须词条：组内满足任一词条，组与组之间都必须满足；旧版扁平必须词条仍按精确 AND 处理。

### 可选综合评分
1. 设置页可开启综合评分，默认关闭。
2. 开启综合评分后，遗物是否合格由其综合评分决定。
3. 所有的正面词条分为三档：核心/次要/锦上添花，默认分值为+10/+6/+2
4. 所有的负面词条分为三档：不可接受/很伤/几乎无负面，默认分值为-12/-4/0
5. 遗物所有词条的正负面分值之和为其综合评分。遗物的保留线默认为 16分+双有效，备选线默认为 10分+双有效。
6. 商店筛选和仓库清理只会保留超过备选线的遗物
7. 上述所有数值均可自定义
8. 旧版预设兼容性：旧版预设可直接导入，导入时评分保持关闭；旧预设中未分级的有效词条在手动启用评分后按“次要”计算。

### 完美遗物与记录
- 满足专用预设且至少3条有效词条、识别无不确定信息时，标记为完美遗物。
- 商店提供“发现完美遗物时停止”开关，默认关闭；开启后保留当前遗物并停止购买。仓库清理会继续处理后续遗物。
- 合格匹配立即追加到用户数据目录下的 `data/relic_history.jsonl`。
- 旧预设无需迁移。普通模式不显示黑名单例外。

通用预设回退、保守停止行为及兼容性说明见 [匹配与安全说明](docs/relic-matching.md)。
分组必须词条的编辑步骤和可选元数据限制见 [分组说明](docs/grouped-requirements.md)。

## 技术特性

- **OCR引擎**：RapidOCR，支持中文识别
- **UI框架**：PySide6 + PySide6-Fluent-Widgets
- **图像处理**：OpenCV（模板匹配、边缘检测）
- **自动化**：pydirectinput / pyautogui
- **数学规划求解器**: scipy
